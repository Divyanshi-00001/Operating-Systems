# Operating Systems

A collection of hands-on C implementations covering Operating Systems concepts and system programming. This repository is continuously updated as I learn and implement new concepts.

## Implemented

- Process Creation using `fork()`
- Parent and Child Processes
- Process IDs using `getpid()` and `getppid()`
- Process Synchronization using `wait()`
- `exec()` System Calls
- Orphan Processes
- Zombie Processes
- Process-based problem solving
- Recursion and Permutation Programs using Child Processes

## Planned Implementations

- CPU Scheduling Algorithms
- Process Synchronization
- Semaphores and Mutex
- Inter-Process Communication (IPC)
- Memory Management
- Paging and Page Replacement
- File Management and File Allocation
- Deadlocks
- Disk Scheduling
- Additional System Calls

## Technologies

- C
- Linux / Unix System Programming
- GCC
- Git & GitHub

## Purpose

This repository documents my practical learning of Operating Systems through hands-on implementation in C, with new concepts and programs added progressively.
